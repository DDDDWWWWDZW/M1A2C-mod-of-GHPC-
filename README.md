# M1A2C for Gunner HEAT PC

First official release: **1.3.1**.

This repository distributes the **compiled/packaged build only**. Source code and
development files are not included here.

## Download

Use the release asset:

```text
M1A2C-1.3.1-official.zip
```

SHA-256:

```text
7F5FCE0E018EEEE954C6C06FA602C36F9AA9BE46510848D63D12575D1C4471C3
```

## Install

1. Install **MelonLoader 0.6.x (net35)** for Gunner HEAT PC.
2. Extract the `M1A2C` folder from the zip into:

```text
<GHPC install>\Bin\Mods\M1A2C
```

3. Start the game.

The folder should contain:

```text
M1A2C.dll
M1A2C_GHPCv2.0.obj
M1A2C_GHPCv2.0.mtl
M1A2C_GHPCv2.0_tusk2.obj
M1A2C_GHPCv2.0_tusk2.mtl
materials.tsv
textures/
```

## Contents

- War Thunder M1A2C visual model
- Independent CROWS weapon station with stabilized sight, laser rangefinder and
  ballistic elevation
- M256 120 mm gun
- M829E3 / M829E4 APFSDS and M830 / M830A1 HEAT
- 42-round loadout: 18 + 18 + 6 racks, 28 AP + 14 HEAT
- Optional TUSK armour with per-block hitzones and two-hit ATAR2 durability
- Gen-3 gunner thermals, 1366x768 high-power FLIR and ~20x digital zoom
- Turret-front wedge composite reinforcement
- Olive paint scheme fixed for this release

Material tuning and paint selection are intentionally hidden in this release.

## Notes
